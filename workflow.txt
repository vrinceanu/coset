### Step 1: Work Locally (Safety First)
Never work directly on your main branch. Create a feature branch to keep your work isolated.

git checkout -b feature/new-cool-thing
# ... edit code, run local development server, test your changes ...

### Step 2: Commit and Push to GitHub
Once the feature is working perfectly on your machine, commit it and send it to GitHub.

git add .
git commit -m "Add new cool feature"
git push origin feature/new-cool-thing

### Step 3: Merge to Main on GitHub
-Go to your GitHub repository in your browser.
-Open a Pull Request (PR) from feature/new-cool-thing into main.
- Review your changes on the GitHub UI.
- If everything looks solid, click Merge Pull Request.

### Step 4: Deploy to Production
Now, tell your production server to grab the updated main branch.
- SSH into your production server.
- Navigate to the project directory.
- Pull the fresh code:

git checkout main
git pull origin main
source venv/bin/activate
python manage.py migrate
python manage.py collectstatic --noinput
sudo systemctl restart gunicorn


### Step 5: Cleanup if succesful deployment
- Delete the branch on GitHub (Remote)
If you didn’t check the box to "Delete branch" immediately after clicking merge on the Pull Request, you can delete it from your terminal:
git push origin --delete feature/new-cool-thing

- Clean up your Local Machine
Even though the branch is gone from GitHub, it still exists on your local laptop. Follow these steps to safely remove it:

- Switch back to your main branch:
You cannot delete a branch while you are actively standing on it.

git checkout main

- Pull the latest changes:
Update your local main branch so your history matches GitHub's merged state.

git pull origin main

- Delete the local feature branch:
Since the code is safely merged into main, you can use the safe delete flag (-d). Git will verify the merge before letting you drop it.

git branch -d feature/new-cool-thing

- Prune your Remote Tracking References (Optional)
Your local Git configuration still remembers that origin/feature/new-cool-thing used to exist. To clear these phantom references out of your local git branch -a list, run a prune:

git fetch origin --prune
